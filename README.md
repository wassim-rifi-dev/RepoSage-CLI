# RepoSage CLI

Outil en ligne de commande écrit en Java avec Spring Boot.

> **Statut :** en développement initial (`v0.0.1`). Le projet contient pour l'instant la base de l'application ; les commandes CLI arrivent dans les prochaines versions.

## Prérequis

- **Java 21** ou supérieur
- Maven n'est pas nécessaire : le projet inclut le Maven Wrapper (`mvnw` / `mvnw.cmd`)

## Installation

```bash
git clone https://github.com/wassim-rifi-dev/RepoSage-CLI
cd RepoSage-CLI
```
